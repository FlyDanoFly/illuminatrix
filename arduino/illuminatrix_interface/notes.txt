Here's the one that I'm trying
https://github.com/Palatis/arduino-softpwm
Forum post declaring its existance:
https://forum.arduino.cc/t/a-really-fast-software-pwm-library/119206

You can't just install it, the default arduino-cli defaults to third-party libraries as unsafe, so first need to turn that off.
> arduino-cli config set library.enable_unsafe_install true

then
> arduino-cli lib install --git-url https://github.com/Palatis/arduino-softpwm

now we'll try it :cross-fingers:

It works **wonderfully**. Subjectively I think it looks nicer than the other library, smoother and softer.
